# 냉큼

연세대학교 기숙사 공용 냉장고 관리 프로토타입입니다.

## 실행

```bash
pnpm install
pnpm dev
```

## Netlify 배포

- Build command: `pnpm build`
- Publish directory: `dist`
- Node: 22

`vite.config.ts`는 외부 Figma 설정 파일 없이 빌드되며, `public/_redirects`가 SPA 새로고침 오류를 방지합니다.

## 확인용 관리자 코드

- 최초 로그인 코드: `RA-2026` (1회용)

로그인한 관리자는 화면 상단의 **코드 발행**에서 다른 관리자용 일회용 코드를 만들고, 복사하거나 사용 전에 회수할 수 있습니다. 관리자 코드와 사용 기록은 현재 브라우저의 localStorage에 저장되는 프로토타입입니다. 실제 출시 시에는 서버 인증, 권한 관리, 발행 감사 로그로 교체해야 합니다.

## 카메라

휴대폰의 HTTPS 주소(Netlify 포함)에서 **카메라 열기**를 누르면 브라우저가 후면 카메라 권한을 요청합니다. 권한이 차단되거나 카메라 API가 없는 브라우저에서는 **사진 선택**을 사용합니다.

## 이번 버전의 핵심 흐름

- **RA 전용 냉장고 구조 관리**: 학생 화면에서는 구조를 수정할 수 없으며, 코드 인증된 RA만 냉장실·냉동고의 선반과 문칸, 신선 서랍 수를 각각 등록
- **위치별 구조 저장**: 학교·기숙사·동·층·냉장고 이름을 묶은 위치별로 구조를 저장해 RA 설정과 학생 현황이 같은 값을 사용
- **대형 냉장고 현황 도식**: 냉장실·냉동고를 별도 탭으로 크게 보고, 칸별 등록 호수와 안전·주의·임박·기한 초과 상태를 색상으로 즉시 확인
- **내 음식**: 개인·공동 등록 음식, 냉장/냉동 위치, 확인기한, 처리 상태를 한 화면에서 확인
- **함께 등록**: 음식 등록 시 공동 소유 호수를 추가하면 같은 음식에 함께 표시
- **공동구매·정산**: 대표자 계좌·수령 장소·인원·마감일을 등록하고, 대표자가 참여자별 입금 여부를 수동 확인
- **보관 안내 자동추천**: 음식 종류와 카테고리에 따라 식품안전나라·식약처 공개 안전자료를 앱용 참고표로 안내
- **10인 파일럿 공용 저장**: RA 2명·학생 8명을 권장하며 Supabase 익명 참가자 세션과 RLS 기반 공용 저장을 선택적으로 연결 (`PILOT_SETUP.md` 참고)
- **RA 냉장고 운영 관리**: 냉장고 추가, 이름·구조 수정, 운영 종료 및 기록 보존 복구
- **알림 설정**: 소비기한, 기한 경과, 부패 위험, 채팅, 공동구매, 위생 제보 알림을 각각 설정
- **전용 글꼴**: `NoonnuBasicGothicRegular.ttf`를 앱과 빌드 결과에 포함
- **UI 리뉴얼**: 참고 이미지의 연두·크림·노랑 팔레트, 둥근 카드, 진한 외곽선, 스티커형 마스코트 요소 적용
- **카테고리 아이콘**: 우유·육류·채소·과일·음료·반찬·냉동식품을 파스텔 스티커 아이콘으로 구분
- **RA 운영 대시보드**: 장기 방치·당일 정리·이번 주 확인 음식, 전체 이용률, 미처리 신고와 공동구매 미입금을 한 화면에서 확인
- **기간별 운영 통계**: 최근 7일·30일·전체의 등록·소비·폐기 활동과 음식물·탄소 절감 추정치를 집계
- **공간 독점 방지**: 소형 1점·중형 2점·대형 3점으로 계산하며 기본값은 1인 총 8점, 냉장 6점, 냉동 4점, 동일 선반 3점
- **RA 보관 정책 설정**: 관리자만 총량·구역별·선반별 한도를 조정하고 학생 등록 화면에 즉시 적용
- **마스코트 배지**: 냉큼 캐릭터에 새싹·눈꽃·나뭇잎·왕관을 조합한 단계별 배지 적용

보관 안내는 제품별 공식 소비기한을 대신하지 않습니다. 포장에 표시된 소비기한과 보관방법이 항상 우선이며, 현재 프로토타입은 앱 알림을 위한 보수적인 참고값을 제공합니다.

공동구매 입금 상태는 금융기관 계좌를 자동 조회하지 않습니다. 개인정보 보호를 위해 대표자가 실제 입금 내역을 확인하고 체크리스트를 갱신하는 방식입니다.

## 데이터 저장

학교·기숙사·사용자 정보, 냉장고 구조, 음식, 공동 소유자, 공동구매·입금 체크, 알림 설정, 신고 사진, 커뮤니티, 포인트·배지는 같은 브라우저의 localStorage에 저장되어 화면을 이동하거나 새로고침해도 유지됩니다. 학생과 관리자는 첫 화면 상단의 역할 전환 버튼으로 구분됩니다.
